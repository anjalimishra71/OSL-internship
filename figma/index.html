Built for the Next Decade of the Web.

The most significant evolution in Drupal's history, engineered for AI-readiness, built on modern PHP standards, and designed to power enterprise digital platforms for the next decade.

The Architecture Behind Drupal 11

Three changes that make Drupal 11 a meaningfully different platform, not just an incremental update.

PHP 8.3+ and Symfony 7

Drupal 11 is built on PHP 8.3 and Symfony 7, delivering stronger performance, modern typing standards, and alignment with the current PHP ecosystem.

A Cleaner, Leaner Codebase

Years of backwards-compatibility layers & deprecated APIs have been removed. Drupal 11's core is smaller, faster, & carries a significantly reduced security attack surface.

Native AI-Module Architecture

The first version of Drupal designed for AI at the platform level, connecting LLMs, vector search, and content automation directly to the content model, not as an add-on.

Where Earlier Drupal Versions Stand Today

Drupal's release lifecycle is well-documented and predictable, each major version receives full security and feature support for approximately four years before reaching end-of-life. Here is the current status of each major version:

Drupal 7

End-of-life January 2025. No further security releases from the Drupal Security Team.

Drupal 9

End-of-life November 2023. No security patches since that date.

Drupal 10

Currently supported. EOL anticipated when Drupal 12 reaches stability.

Drupal 11

The current long-term supported release, with active security and feature development.

Organisations running Drupal 7 or 9 are operating platforms that no longer receive security patches from the Drupal community.

What Drupal 11 Makes Possible

Headless and Decoupled by Default

JSON:API and REST API ship enabled out of the box, serving any frontend (React, Next.js, mobile, IoT) from a single content hub, with the content and presentation layers fully independent.

AI Integration at the Content Model Level

The Drupal AI module connects AI providers directly to Drupal's entity system, classifying, summarising, tagging, and generating content using structured data already in Drupal, no separate AI platform needed.

Performance Improvements Without Extra Configuration

Improved BigPipe, enhanced cache propagation, and a leaner core reduce page generation overhead measurably, sites migrating from D9 or D10 consistently report Core Web Vitals improvements out of the box.
